## The permutation (fixed)

P16 = w101's `perm101.gperm(R, 16)`, the one every #130 quant used: stored row j holds natural row perm[j]. With
nb = R / 128, k = j >> 4 (stored 16-row group), c = j & 15: **natural row = 16 (8 (k mod nb) + ⌊k / nb⌋) + c.**
(The kernel note's "stored 128 b + 16 t + c → natural 16 (b + nb t) + c" is this map's inverse; it is the same
function only when nb = 8. The kernel implements gperm, as quantized.) The GEMM's stored output column j goes to
natural column perm[j]; an 8-column aligned vector stays inside one 16-column group, so every store stays one vector.
