TP ∈ {1, 2, 4} for this model (attention refuses world > n_head_kv = 4; 24 q heads, 16 / 48 GDN k / v heads divide

natural 128-row Hadamard block is inside one rank; the TP 4 sets nest in the TP 2 sets (TP 2 rank ρ = TP 4 ranks 2ρ,
2ρ + 1, part by part). exl3i (V3) weights refuse TP > 1 today (a record split is not written yet); EXL3 (V2) weights
row-shard as above.

Full P16 (gperm(N, 16): stored block = one 16-row tile of each of 8 consecutive natural blocks) is not TP-safe: at
TP 4, 48 / 80 ssm_qkv and 16 / 48 ssm_z stored blocks hold rows of two ranks; attn_v / attn_k blocks span ranks already
at TP 2; and even where the row sets fit (TP 2, attn_qg at TP 4) the blocks sit at other ranks' positions, so the
loader would need a block gather.

## The arms (fixed)

perm[j] = the natural row stored at row j (perm101's convention). `w113/perm113.py`:
- **N** natural; **P** = full P16, `gperm(N, 16)` (w101 / w111's arm);
- **T = P16-TP** = `tpperm(parts, 4)`: inside every TP 4 rank set S_r (its rows in increasing order, n = N / 4),
  stored position S_r[i] holds natural row S_r[gperm(n, 16)[i]]. Interleave width (natural 128-row blocks a stored
  block): ssm_qkv 8 (nb 20 a rank: q, k and v heads of the rank mix), ssm_z 8 (nb 12), attn_qg 8 (nb 24; the same block
  row sets as P, at other positions), attn_v / attn_k **2** (nb 2 = the rank's one KV head: each stored block = tiles 0–3
  or 4–7 of both its blocks; the widest TP 4-feasible). One stored order serves TP 1 / 2 / 4; the loader cut is
  unchanged (each rank's stored positions are its natural positions as a set; no gather, no cross-rank data).
- **V** (report only, v_proj): `tpperm(parts, 2)`, width 4, serves TP 1 / 2 only.

**Kernel map (closed form, no table)**, serving TP t, nest 4, m = 4 / t: c_p = part p's 16-row tiles a TP 4 rank, C_p
their prefix sums, nb = C_n / 8. Local stored tile k (= j >> 4): part p with m C_p ≤ k < m C_{p+1}; o = k − m C_p;
s = ⌊o / c_p⌋; i = C_p + (o mod c_p); j4 = 8 (i mod nb) + ⌊i / nb⌋; part q with C_q ≤ j4 < C_{q+1}; local natural
tile = m C_q + s c_q + (j4 − C_q); natural row = 16 tile + (j & 15). One part: natural tile = s·8nb + 8 (k' mod nb) +
⌊k' / nb⌋ with s = ⌊k / 8nb⌋, k' = k mod 8nb. Checked == the table for every rank at TP 1 / 2 / 4, all five families.
