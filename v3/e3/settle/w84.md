## What is measured, and how the arm is built (design choice, stated before data)

The residual permutation P (40 blocks of 128) changes exactly one thing in the quantized model: **the order in which
LDLQ visits the 128-blocks of every residual reader's input** (GDN in_proj_qkv / in_proj_z, attention q / k / v,
gate / up; 272 tensors). Everything else is equivariant under a whole-128-block permutation: the 128-Hadamard is
block-diagonal, su / sv / suh / svh are per channel, the trellis tiles are 16×16 inside one block, the global scale
and the scale refit are per tensor / channel, and the writers' LDLQ runs over their own (non-residual) inputs. So
"quantize the converted (permuted) model, then store" equals "quantize the natural model with LDLQ visiting the blocks
in P's order (natural block P[39] first, since exllamav3 runs last-to-first), then store in natural order", tile for
tile, **provided** the converted run draws the natural run's per-position random signs permuted along (the sign trap)
and its global-scale tile sample maps through P (exllamav3 samples a wrapped tile diagonal, which is not equivariant).

The pairs therefore use the second form (**route B**, `w84/blkorder84.py`: wraps exllamav3's `scaled_ldl` and `ldlq`
for the 272 readers only; rxq quant with the control level's own settings): the arm differs from its control in the
readers' LDLQ order and nothing else — same signs, same g_scale sample, writers / embedding / head / norms / V2 base
bit-identical by construction. The converted-model form (**route A**) is built too (item 1) and checked against
route B on real tensors (gate G2), so the pairs measure the converted model's quant exactly.

## Item 1 · conversion tool + gates

- `w84/perm117.py`: P applied to the bf16 checkpoint (w82's list: readers' input columns incl. in_proj_a / b; writers'
  output rows; input_layernorm / post_attention_layernorm / model.norm; embed_tokens and lm_head columns; vision
  merger linear_fc2 rows + bias; MTP pre_fc norms, both halves of mtp.fc's input columns and its rows, the MTP layer's
  readers / writers / norms, mtp.norm), to the calib input Hessians (layers.N.input, layers.N.post_attention.input,
  lm_head.input: rows and columns of the packed upper triangle; the rest linked) and to H_out files (writers' rows,
  i.e. hout_diag / both axes of hout; readers' H_out untouched). Every checkpoint tensor with a 5120 dimension must be
  classified (permuted or listed as non-residual), else the tool refuses. DFlash2 (separate checkpoint) is documented.
- **G1 noop gate (card 0):** route B with the identity order, rxq with the control's settings (`rxq levelargs`, tile
  CD off, H_out off), on 9 reader tensors (layer 0: ssm_qkv, ssm_z, gate, up; layer 3: q, k, v, gate, up), at both
  seeds: `rxq.pairs same CONTROL JOBDIR` must PASS (bit-identical). If a seed's gate fails, its control becomes a
  fresh noop level (all 272 readers requantized with the identity order, spliced into the control), packed and scored.
- **G2 route A ≡ route B (card 0, `w84/signchk84.py`), the sign-trap proof:** on layer 0 (ssm_qkv, ssm_z, ssm_out) and
  layer 3 (q, k, v, o_proj): route A = the converted tensor (perm117's own functions on W and on the packed calib H)
  quantized with natural signs permuted along and the g_scale sample mapped through P; route B = the natural tensor
  with the order patch. Check: the LDLQ inputs (rotated weight and L) of A equal P·(B's) and the stored trellis codes of
  A equal B's codes moved by P (bit for bit); suh / svh equal up to the refit's float reordering (reported as max f16
  ulps). Also run: route A **without** the sign permutation (what a plain converted run does) → expected O(1)
  differences in the LDLQ input and most codes changed (= a reseed). PASS = trellis bit-identical on every checked
  tensor with signs handled. A FAIL stops the pairs until explained.
- **G3 bf16 gate (CPU, colo, `w84/gate84.py`):** layer-streamed forward of the original and the converted bf16 model
  (perm117's per-tensor function applied on load) on the first 512 tokens of 2 fit-pool calib docs, in fp32 and fp64;
  also the MTP head (fc + its layer + norm + lm_head) and the vision merger fc2 on a fixed input. PASS: logits bitwise
  equal, or max |Δlogit| at fp64 ≤ 1e-9 × max |logit| (pure float reassociation: the fp32 difference must shrink by
  ≥ 10⁵ at fp64) and top-1 identical. Not a precondition for the pairs (they do not use the converted checkpoint), but
  for shipping the converter.

## Item 2 · the rule (user's standard, as for H_out)

Two seed pairs at **K2.5, plain levels** (no H_out, no tile CD, no swj, no C9): controls `/data/v3ladder2/K2.5` (seed 0,
"base") and `/data/swap27/q-s1/K2.5` (seed offset 1, "s1"), the matched natural-order controls of the swap27 series.
Choice: plain (not H_out) because these controls exist and a plain arm costs ~25–40 min of card 0 per level; the
permutation acts on the readers' LDLQ order, which H_out does not change (H_out is a readers' output-side factor).
Arm = control with the 272 readers requantized by route B in the consensus order (`order82.json`), spliced
(`rxq.pairs splice`, level hygiene `rxq.pairs levels` must be PAIR OK), packed (exl3i, mul1i8, rate 2.5), mixed into
the same V2 3.00 (`radmix`), census, mix hygiene `rxq.pairs mixes ARM CONTROL --arm <readers>` must be PAIR OK (if
the stored control mix differs outside the readers, a fresh control is packed from the control level and scored).
Scored on golden-search27 (search pool, 103 docs, 123,460 scored positions; radiance, bf16 KV, card 0), paired with
`tools/paired.py` (control rows → arm rows). The stored control rows are used if a re-score of the control mix
reproduces them bit for bit; otherwise the fresh control rows.

- r_s = kld(arm) / kld(control) per seed pair; g = exp(mean log r).
- **ADOPT** (permute at every level, before the ladder freeze) if **r_base < 1 and r_s1 < 1**.
- **NOT ADOPTED** if both r ≥ 1.
- **Ambiguous** if one is < 1 and the other ≥ 1 → a K4 pair (controls `/data/swap27/q-base4/K4` and
  `/data/swap27/q-base4s1/K4`, plain) is the next step; queued only on the lead's go (a K4 level took ~6 h of card 0).
- Reported, not deciding: g, z per pair (paired.py, document bootstrap), the pooled z, rel SE; p99 of the per-position
  KL and top-1 agreement on the scored positions, arm vs control; the context of w81's floors (same-seed pair SD
  0.0086, cross-seed σ 0.0178); the readers' one-sided proxy ratio arm / control (rxq logs) next to w82's settle64.
- **Runtime cost: none** (format and kernels unchanged; with route B nothing outside the quantizer changes at all).
